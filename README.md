# Build Cycle C04

**The Upskilling Labs of Greater Washington · Oct 24 to Dec 8, 2026**

A Build Cycle is six weeks in which a group of neighbors picks a hard problem, researches it properly, and builds something real in response. This Cycle, for the first time, the problem is The Labs itself: how it teaches, how it's seen, and where it lives.

This repo is the home for the whole Cycle. Each Research Pod has its own repo, linked below.

## How we work

We use **frame creation**, a research method from designer Kees Dorst (*Frame Innovation*, 2015). Hard problems stay hard because everyone looks at them the same way. So we study the problem first, find the **paradox** (two things that are both true and pull against each other), and look for a **frame**: a new way of seeing the problem that makes the paradox easier to move. Only then do we build.

Each pod's README walks through Dorst's nine steps, what evidence we're collecting, and how to turn it in.

## Who does what

- **Pod maintainers** run a pod's repo, recruit, and keep the research moving. Each pod starts with one and grows to three to five.
- **Builders in residence** commit 4 to 6 hours a week through Dec 8. After Nov 14, each leads one project and recruits a team. Every builder in residence is a maintainer of their pod.
- **Contributors** give what time they have: an interview, a case study, a record, a review. No coding needed.

## When

Most of us work nights and weekends, so weekly work is due **Monday night**. On **group days**, when the whole Cycle meets, work is due when the day starts.

| Due | What |
|---|---|
| **Mon Nov 2** | One interview per builder, logged. Each pod posts "What surprised us." |
| **Sat Nov 7, group day** | All archaeology in. Pods write the paradox. Each builder leaves with a frame. |
| **Nov 8 to 13** | Rapid prototype of each frame, tried by three real people. |
| **Sat Nov 14, group day** | Project proposals pitched. The room votes. Teams form. |
| **Mon Nov 23, Nov 30, Dec 7** | Weekly releases to real people. |
| **Tue Dec 8, group day** | Teach-back. We ship. |

**Open Lab Nights:** the Cycle votes on which weeknight(s) we keep open for working together.

## Why this lives here

The Upskilling Labs of Greater Washington is becoming its own regional association. This GitHub organization, like the region's address at wash.upskillinglabs.org, is where the region's work lives and where its volunteers manage their own access.

We build on **OLOS**, The Labs' open-source platform. The Upskilling App at theupskillinglabs.org is the national organization's copy of it. Greater Washington runs its own copy, changes it to fit how the region works, and sends what holds up back to the main OLOS project as pull requests. The region builds and proves. The core keeps and carries.
